# 子任务 2：ECharts 复杂图表与数据大屏

> 一套可直接双击打开（无需构建、无需联网）的 1920×1080 经营数据大屏，
> 覆盖折线 / 柱状 / 散点 / 热力 / 地图 5 类图表，并实现 scale 方案自适应。

## 1. 目录结构

```
echarts/
├── index.html              # 大屏页面（唯一入口）
├── css/screen.css          # 视觉设计与布局（深空蓝 + 青色发光 + 卡片化）
├── js/main.js              # 5 类图表配置、KPI 数字滚动、时钟、自适应缩放
├── data/
│   ├── dashboard_data.js   # 大屏数据（window.DASHBOARD_DATA，离线可用）
│   ├── dashboard_data.json # 同一份数据的 JSON 版本（供后端接口返回）
│   └── china_geo.js        # 中国地图 GeoJSON（window.CHINA_GEO，离线可用）
├── static/
│   ├── echarts.min.js      # ECharts 5.5.0（本地化，不依赖 CDN）
│   └── china.json          # 地图原始 GeoJSON
├── gen_data.py             # 生成数据（可替换为 Hive 取数）
└── api_server.py           # 零依赖 JSON 接口服务
```

## 3. 图表设计说明

| 图表 | 类型 | 数据字段 | 设计要点 |
|---|---|---|---|
| 销售趋势 | 折线（双 Y 轴 + 面积渐变） | `trend[].month/gmv/order_cnt` | 左轴 GMV(亿元)、右轴订单量(单)；峰值点金色标记；2 月低谷、11 月峰值一目了然 |
| 区域销售分布 | 地图（Chine Map） | `regions[].province/gmv` | 连续型视觉映射，深蓝→青→金；5 秒轮播高亮省份，便于讲解 |
| 品类销售对比 | 横向柱状 | `categories[].category/gmv` | 按 GMV 升序绘制（顶部最大），渐变条 + 右端数值标签 |
| 时段 × 品类热力 | 热力图 | `heatmap.x/y/data` | 8 个时段 × 9 个品类，识别 18:00-21:00 晚高峰 |
| 客单价 × 销量 | 气泡散点 | `scatter[].value[客单价, 销量, GMV]` | 气泡大小映射 GMV，观察「高单价低频」与「低单价高频」品类分布 |

KPI 行：GMV、订单量、下单用户数、客单价、复购率、在售品类（数字滚动动画 + 同比标签）。

### 3.1 图表联动（跨图筛选）

大屏内置一套「月份 × 省份 × 品类」三维立方体（`DATA.cube`，2,160 个单元格，
由 `gen_data.py` 用三维 IPF 生成，三个维度汇总均严格等于原始口径），所有图表都从
同一份立方体按当前筛选条件聚合，因此任一图表筛选后其余图表同步重算。

| 触发位置 | 交互 | 联动效果 |
|---|---|---|
| 地图省份 | 单击选中 / 再次点击取消 | 折线按该省逐月重算、品类柱与散点按该省重算、热力按该省 GMV 占比缩放、KPI 与页脚同步 |
| 品类横条 / 散点气泡 / 热力行 | 单击 / 再次点击取消 | 地图只显示该品类的省域分布、折线只显示该品类月度走势、热力仅保留该品类行、其余图表高亮该品类 |
| 折线月份点 | 单击可多选 / 再次点击取消 | 地图、品类柱、散点、热力按所选月份聚合 |
| 页头金色标签 × | 单击移除单个条件 | 其余条件保留，实时重算 |
| 「重置」按钮 | 单击 | 清空全部筛选，恢复全量口径 |

- 页头左侧实时显示筛选标签；未筛选时提示「点击地图 / 柱状 / 月度点 / 气泡联动」；
- 页脚显示当前筛选范围与筛选后的 GMV、订单量；
- KPI 卡中 GMV / 订单量 / 客单价 / 在售品类随筛选变化，下单用户数与复购率
  仅有全量口径，筛选时标注「全量口径 · 不随筛选」，避免口径误导；
- 用户一旦交互，地图的 5 秒轮播高亮自动停止，避免与手动选择冲突。

## 4. 自适应方案（scale）

- 设计稿固定 `1920×1080`，所有尺寸按设计稿写死，保证像素级还原；
- `resizeStage()` 计算 `scale = min(window.innerWidth/1920, window.innerHeight/1080)`，
  通过 `transform: translate(-50%,-50%) scale(scale)` 等比缩放并居中；
- `resize` 事件做 120ms 防抖，缩放后同步调用 `chart.resize()`；
- 效果：1366×768、1600×900、1920×1080、2560×1440 均可完整显示，无滚动条、无拉伸变形。

## 5. 视觉设计

| 元素 | 方案 |
|---|---|
| 背景 | 深空蓝 `#050b1a` + 双径向光晕 + 48px 细网格纹理 |
| 主色 | 青 `#22d3ee` / 蓝 `#3b82f6`；强调色金 `#fbbf24` |
| 卡片 | 半透明面板 + 1px 蓝色描边 + 左上/右下 L 型角标 |
| 标题 | 34px 渐变文字 + 底部发光分隔线；中英文双语副标题 |
| 留白 | 栅格 12 列、间距 12px、面板内边距 14px，信息密度高但不拥挤 |
| 动效 | KPI 数字滚动、地图轮播高亮、折线发光、气泡径向渐变 |

## 6. 数据口径

`gen_data.py` 使用确定性随机种子（`20241111`），与第 3 周 ADS 层结论一致：

- 全年 GMV：6.61 亿元；订单量：15,000 单；下单用户：8,932 人；客单价：440.67 元；复购率：31.2%
- 月度分布：11 月大促峰值（14.5%）、2 月春节低谷（5.5%）
- 品类 9 个、省份 20 个、支付方式 4 种、渠道 4 种

**接入真实数据**：修改 `gen_data.py` 的 `build_from_hive()`，按现有 JSON 结构从
`ydsh_ads.ads_sales_daily / ads_category_topn / ads_region_sales / ads_pay_type_daily` 查询即可，
前端无需改动。
