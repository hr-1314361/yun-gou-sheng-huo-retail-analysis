## 系统入口

| 系统 | 访问地址 | 说明 |
|---|---|---|
| ECharts 数据大屏 | http://localhost:8848 | 离线可用，支持跨图联动 |
| Streamlit NL2SQL | http://localhost:8502 | 对话式问答（需启动） |
| Apache Superset | http://localhost:8088 | BI 仪表板（需 Docker） |

## 一键部署

```bash
cd 第4周-胡蕊/docker
cp .env.example .env   # 配置密码与 DeepSeek API Key
docker compose up -d --build
```
