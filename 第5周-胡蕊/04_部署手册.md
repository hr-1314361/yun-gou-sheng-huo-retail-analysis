# 部署手册

> 项目：云购生活新零售企业 —— 企业级数据仓库与经营分析可视化系统
> 版本：v4.0（第 4 周）　适用环境：Windows / Linux + Docker Desktop / Docker Engine
> 配套文件：`docker/docker-compose.yml`、`docker/.env.example`、`docker/README.md`

---

## 一、系统架构

```
┌────────────────────────────────────────────────────────────────────┐
│                         用户访问层                                   │
│   Superset 仪表板 :8088      Streamlit 智能问数 :8501   ECharts 大屏  │
└───────────────┬──────────────────────┬─────────────────────────────┘
                │                      │
┌───────────────▼──────────────────────▼─────────────────────────────┐
│                         服务层                                       │
│  Superset(Flask/Gunicorn)   Python App(Streamlit + NL2SQL)          │
│  Redis 图表缓存              ClickHouse OLAP 即席分析                 │
└───────────────┬──────────────────────┬─────────────────────────────┘
                │ SQLAlchemy           │ PyHive / JDBC
┌───────────────▼──────────────────────▼─────────────────────────────┐
│                         数据层                                       │
│  HiveServer2 :10000 → Hive Metastore :9083 → MySQL :3306(元数据)     │
│  数仓分层：ODS → DWD → DWS → ADS（Parquet）                          │
└────────────────────────────────────────────────────────────────────┘
```

数据流：`业务数据 → ODS → DWD 明细 → DWS 汇总 → ADS 应用层 → Superset / ECharts / Streamlit`

## 四、一键部署步骤

### 步骤 1：准备环境变量

```powershell
cd 第4周-胡蕊\docker
copy .env.example .env
notepad .env
```

`.env` 至少修改：

```ini
MYSQL_ROOT_PASSWORD=<强密码>
SUPERSET_SECRET_KEY=<32位随机字符串>
SUPERSET_ADMIN_PASSWORD=<管理员密码>
CLICKHOUSE_PASSWORD=<强密码>
DEEPSEEK_API_KEY=sk-xxxx        # 留空则进入演示模式
```

生成随机密钥：

```powershell
python -c "import secrets;print(secrets.token_urlsafe(32))"
```

### 步骤 2：启动

```powershell
# 方式一：脚本
.\start.ps1

# 方式二：命令
docker compose up -d --build
```

首次启动会构建 Hive / Superset / App 镜像并拉取 MySQL、ClickHouse、Redis，
耗时取决于网络。Hive Metastore 首次初始化需要 1~3 分钟。

### 步骤 3：检查服务状态

```powershell
docker compose ps
```

期望结果（7 个服务，除 python-app 外均应为 `healthy`）：

| 服务 | 容器名 | 状态 | 端口 |
|---|---|---|---|
| mysql | ydsh-mysql | healthy | 3307 |
| hive-metastore | ydsh-hive-metastore | healthy | 9083 |
| hive-server2 | ydsh-hive-server2 | healthy | 10000 / 10002 |
| clickhouse | ydsh-clickhouse | healthy | 8123 / 9000 |
| redis | ydsh-redis | healthy | 内部 |
| superset | ydsh-superset | healthy | 8088 |
| python-app | ydsh-python-app | running | 8501 |

### 步骤 4：验证各服务

```powershell
# Hive
docker exec -it ydsh-hive-server2 beeline -u "jdbc:hive2://localhost:10000/default;auth=noSasl" -e "show databases;"

# ClickHouse
docker exec -it ydsh-clickhouse clickhouse-client --password $env:CLICKHOUSE_PASSWORD -q "SELECT version()"

# Superset
curl http://localhost:8088/health

# Streamlit
curl http://localhost:8501/_stcore/health
```

## 五、初始化数仓数据

### 5.1 建库建表

将第 1~3 周的建表与 ETL 脚本按顺序执行：

```powershell
# 复制 SQL 到容器
docker cp ..\..\sql ydsh-hive-server2:/tmp/sql

# 执行（示例：ODS/DWD 建表 + 第3周 DWS/ADS）
docker exec -it ydsh-hive-server2 beeline -u "jdbc:hive2://localhost:10000/default;auth=noSasl" -f /tmp/sql/dws/01_ddl.sql
```

> 路径以实际提交目录为准；也可在 Superset SQL Lab 中逐段执行。

### 5.2 增加第 4 周 ADS 扩展表

```powershell
docker exec -it ydsh-hive-server2 beeline -u "jdbc:hive2://localhost:10000/default;auth=noSasl" -f /tmp/superset/sql/00_ads_extend.sql
```

## 六、Superset 配置

1. 浏览器打开 http://localhost:8088，使用 `admin` / `.env` 中的密码登录；
2. 连接 Hive：`hive://hive@hive-server2:10000/ydsh_ads`；
3. 连接 MySQL：`mysql+pymysql://root:<密码>@mysql:3306/ydsh_ads`；
4. 按 `superset/datasets.sql` 创建 6 个 Dataset；
5. 按 `superset/charts_dashboard.md` 制作 5 个图表并组装仪表板。

详细步骤见 `superset/README.md`。

## 十、故障排查

| 现象 | 排查命令 | 处理 |
|---|---|---|
| Hive Metastore 反复重启 | `docker compose logs hive-metastore` | 检查 MySQL 是否 healthy；确认 JDBC 驱动已 COPY 进镜像；确认 `hive-site.xml` 密码变量已注入 |
| HiveServer2 启动后立即退出 | 同上 | 确认 metastore 为 healthy；检查 `hive.metastore.uris` 主机名 |
| Superset `500` / 无法登录 | `docker compose logs superset` | 确认 `SUPERSET_SECRET_KEY` 已设置；`superset db upgrade` 是否执行成功 |
| Superset 报 `No module named pymysql` | — | `docker compose build --no-cache superset && docker compose up -d superset` |
| 8501 打开显示演示模式 | 页面顶部胶囊 | 未配 Key 或 Hive 未就绪；修复后点侧边栏「重测连接」 |
| 端口冲突 | `netstat -ano \| findstr :8088` | 修改 compose 端口映射 |
| 容器内存不足 | `docker stats` | 提高 Docker Desktop 内存到 16GB |

### 答辩应急方案

| 风险 | 预案 |
|---|---|
| Docker 启动失败 | 直接演示已录制的启动过程视频 + 本地大屏 HTML |
| Hive 未就绪 | Streamlit 自动降级演示数据，不影响流程演示 |
| 网络不可用 | 大屏与 ECharts 库全部本地化，Superset 已登录可直接演示 |
| 大模型额度不足 | 预置 6 个示例问题，走本地演示数据 |
