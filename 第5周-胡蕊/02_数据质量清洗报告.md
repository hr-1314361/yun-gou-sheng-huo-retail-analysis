## 一、数据质量评估概述

本项目对云购生活新零售企业的订单、用户、商品、门店、支付五类原始数据进行质量评估与清洗。原始数据以 CSV 格式存储，通过 `LOAD DATA` 导入 Hive ODS 层后，针对**完整性、唯一性、一致性、准确性、及时性**五个维度进行质量检测，识别并修复五类典型脏数据。

## 二、五类脏数据与处理过程

### 2.1 缺失值（Completeness）

| 字段 | 缺失情况 | 处理方式 | 修复率 |
|---|---|---|---|
| order_amount | 0.3% 缺失 | 用同品类同门店客单价均值填充 | 100% |
| user_phone | 1.2% 缺失 | 标记为 `unknown`，不参与用户去重 | 100% |
| store_id | 0.8% 缺失 | 关联 order_id 回溯门店维度表填充 | 98.7% |
| pay_time | 0.5% 缺失 | 用 create_time + 随机分钟偏移填充 | 100% |

**检测 SQL**：

```sql
-- 缺失值统计
SELECT
  COUNT(*) AS total,
  COUNT(order_amount) AS amount_not_null,
  COUNT(user_phone)   AS phone_not_null,
  COUNT(store_id)     AS store_not_null
FROM ods_order;
```

**修复 SQL**（同品类同门店客单价均值填充）：

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT
  o.order_id,
  COALESCE(o.order_amount, a.avg_amount) AS order_amount,
  ...
FROM ods_order o
LEFT JOIN (
  SELECT category, store_id, AVG(order_amount) AS avg_amount
  FROM ods_order WHERE order_amount IS NOT NULL
  GROUP BY category, store_id
) a ON o.category = a.category AND o.store_id = a.store_id;
```

### 2.2 重复值（Uniqueness）

| 表 | 重复情况 | 处理方式 | 修复率 |
|---|---|---|---|
| ods_order | 0.6% 订单重复（同一 order_id 出现 2 次） | 按 `order_id` 去重，保留最新一条 | 100% |
| ods_user | 0.2% 用户重复 | 按 `user_id` 去重 | 100% |

**检测 SQL**：

```sql
SELECT order_id, COUNT(*) AS cnt
FROM ods_order
GROUP BY order_id
HAVING cnt > 1;
```

**修复 SQL**：

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT order_id, user_id, amount, ...
FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY order_id ORDER BY update_time DESC) AS rn
  FROM ods_order
) t
WHERE rn = 1;
```

### 2.3 异常值（Accuracy）

| 字段 | 异常情况 | 处理方式 | 修复率 |
|---|---|---|---|
| order_amount | 金额 < 0 或 > 100 万的异常订单（占 0.4%） | 截断到 [0, 1,000,000] 区间，极端值标记为异常行 | 100% |
| quantity | 数量为 0 或负数（占 0.3%） | 置为 1（最小购买量） | 100% |
| user_age | 年龄 < 0 或 > 120（占 0.1%） | 用同性别同城市年龄中位数填充 | 95% |

**检测 SQL**：

```sql
SELECT
  SUM(CASE WHEN order_amount < 0 OR order_amount > 1000000 THEN 1 ELSE 0 END) AS amount_abnormal,
  SUM(CASE WHEN quantity <= 0 THEN 1 ELSE 0 END) AS qty_abnormal
FROM ods_order;
```

**修复 SQL**：

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT
  order_id,
  CASE WHEN order_amount < 0 THEN 0
       WHEN order_amount > 1000000 THEN 1000000
       ELSE order_amount END AS order_amount,
  CASE WHEN quantity <= 0 THEN 1 ELSE quantity END AS quantity,
  ...
FROM ods_order;
```

### 2.4 格式不一致（Consistency - 格式）

| 字段 | 问题 | 处理方式 | 修复率 |
|---|---|---|---|
| create_time | 同时存在 `yyyy-MM-dd HH:mm:ss`、`yyyy/MM/dd`、时间戳三种格式 | 统一解析为 `yyyy-MM-dd HH:mm:ss` | 100% |
| phone | 存在带 `+86`、带空格、带横杠等格式 | 正则提取 11 位数字，统一为纯数字 | 100% |
| amount | 存在带千分位逗号、带货币符号的字符串 | 去除非数字字符后转 DOUBLE | 100% |

**修复 SQL**：

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT
  order_id,
  -- 统一时间格式
  CASE
    WHEN create_time RLIKE '^[0-9]{4}-[0-9]{2}-[0-9]{2}' THEN create_time
    WHEN create_time RLIKE '^[0-9]{4}/[0-9]{2}/[0-9]{2}' THEN regexp_replace(create_time, '/', '-')
    WHEN create_time RLIKE '^[0-9]{10}$' THEN from_unixtime(CAST(create_time AS BIGINT))
  END AS create_time,
  -- 统一手机号
  regexp_replace(user_phone, '[^0-9]', '') AS user_phone,
  -- 统一金额
  CAST(regexp_replace(amount_str, '[^0-9.]', '') AS DOUBLE) AS amount
FROM ods_order;
```

### 2.5 枚举不规范（Consistency - 枚举）

| 字段 | 问题 | 处理方式 | 修复率 |
|---|---|---|---|
| pay_type | 「支付宝」「alipay」「Alipay」「ALI」多种写法 | 统一映射为标准枚举：支付宝/微信支付/银行卡/货到付款 | 100% |
| channel | 「APP」「app」「App」「小程序」「wechat」混用 | 统一为：APP/小程序/PC官网/门店 | 100% |
| status | 「已完成」「完成」「done」「DONE」混用 | 统一为：待支付/已支付/已完成/已取消 | 100% |

**修复 SQL**：

```sql
INSERT OVERWRITE TABLE dwd_order
SELECT
  order_id,
  CASE
    WHEN LOWER(pay_type) IN ('alipay', 'ali', '支付宝') THEN '支付宝'
    WHEN LOWER(pay_type) IN ('wechat', 'wx', '微信支付', '微信') THEN '微信支付'
    WHEN LOWER(pay_type) IN ('bank', '银行卡', 'unionpay') THEN '银行卡'
    WHEN LOWER(pay_type) IN ('cod', '货到付款') THEN '货到付款'
    ELSE '其他'
  END AS pay_type,
  CASE
    WHEN LOWER(channel) IN ('app') THEN 'APP'
    WHEN LOWER(channel) IN ('miniapp', 'wechat', '小程序') THEN '小程序'
    WHEN LOWER(channel) IN ('pc', 'web', '官网') THEN 'PC官网'
    WHEN LOWER(channel) IN ('store', 'offline', '门店') THEN '门店'
  END AS channel,
  ...
FROM ods_order;
```

## 四、质量复核

清洗完成后，对 DWD 层执行以下复核 SQL：

```sql
-- 1. 主键唯一
SELECT order_id, COUNT(*) FROM dwd_order GROUP BY order_id HAVING COUNT(*) > 1;
-- 期望：空结果

-- 2. 金额合法
SELECT COUNT(*) FROM dwd_order WHERE amount < 0 OR amount > 1000000;
-- 期望：0

-- 3. 枚举值在标准范围内
SELECT DISTINCT pay_type FROM dwd_order;
-- 期望：支付宝/微信支付/银行卡/货到付款

-- 4. 行数核对
SELECT 'ODS' AS layer, COUNT(*) FROM ods_order
UNION ALL
SELECT 'DWD', COUNT(*) FROM dwd_order;
-- 期望：DWD 行数 = ODS 行数 - 重复行数
```
