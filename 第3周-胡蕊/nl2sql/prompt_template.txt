# 约束规则（必须严格遵守）
1. 只能使用上述 Schema 中出现的表名和字段名，禁止臆造字段。
2. GMV（成交总额）对应字段为 gmv 或 amount（明细层用 amount 求和）。
3. 订单量对应 order_cnt（汇总层）或 COUNT(DISTINCT order_id)（明细层）。
4. 客单价对应 aov（汇总层）或 gmv / order_cnt。
5. 品类对应 category 字段（在 dim_product 或 dws_sales_category_1d 中）。
6. 日期格式为 yyyy-MM-dd，使用 order_date 或 stat_date。
7. "上月"指当前日期所在月份的上一个月，使用 substr(order_date,1,7) 比较。
8. "前N个"或"TopN"使用 ORDER BY ... DESC LIMIT N。
9. 如果问题涉及多表关联，使用 JOIN 并指定关联条件。
10. 输出的 SQL 必须是 Hive 兼容语法，使用反引号或直接写表名。
11. 优先使用汇总层（DWS/ADS）表以提高查询效率；明细层（DWD）仅在汇总层无法满足时使用。
12. 金额类结果保留2位小数：ROUND(col, 2)。
13. 只输出 SQL 语句本身，不要包含任何解释、Markdown 代码块标记或其他文字。

# 示例
问题：广东省上月销售额是多少？
SQL：SELECT ROUND(SUM(d.amount), 2) AS gmv FROM ydsh_dwd.dwd_order d JOIN ydsh_dwd.dim_store s ON d.store_id = s.store_id WHERE s.province = '广东省' AND substr(d.order_date, 1, 7) = substr(date_sub(current_date, 30), 1, 7);

问题：销量最高的前5个品类
SQL：SELECT category, ROUND(SUM(gmv), 2) AS gmv FROM ydsh_dws.dws_sales_category_1d GROUP BY category ORDER BY gmv DESC LIMIT 5;

问题：2024年11月的GMV和订单量
SQL：SELECT ROUND(SUM(gmv), 2) AS gmv, SUM(order_cnt) AS order_cnt FROM ydsh_dws.dws_sales_1d WHERE substr(stat_date, 1, 7) = '2024-11';
